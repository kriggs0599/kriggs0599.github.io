# Kenneth Riggs personal portfolio refresh

A mobile-friendly, static portfolio for GitHub Pages. It uses HTML, CSS, and a small JavaScript file; no build process or external JS dependencies are needed. Fonts are loaded from Google Fonts if available, with local sans-serif fallbacks.

## Publish
1. Download and unzip the archive.
2. In your `kriggs0599.github.io` GitHub repository, upload the included `index.html`, `projects.html`, `contact.html`, `style.css`, and `script.js` to the `main` branch, replacing files with matching names.
3. Confirm GitHub Pages is enabled for this branch under **Settings → Pages**.
4. Visit `https://kriggs0599.github.io/` after deployment.
